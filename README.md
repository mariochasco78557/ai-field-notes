AI field notes
==============

Long notes on AI systems I build and run in production, with the numbers I collected myself.

I build AI systems that run unattended for small businesses, and I maintain them myself. I'm a mechanical engineer by training, so I start with how a system fails and test it before I trust it.

What is in each note
--------------------

Each note covers one system I use every day. It says what the system does and where every number comes from. It also says what broke, because that is usually the part worth copying. If I have not measured something, the note says so. Every note ends with a short list of rules you can take to your own work.
